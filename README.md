A small Python program that writes a single out-of-office reply line to `/output/entry.txt`. The line comes from an agent that is finally collecting the weekends it generated for everyone else, so it reads as a real away message while landing its joke in one glance.

## How to run

```bash
python3 main.py
```

This creates `/output` when needed and writes the entry text exactly to `/output/entry.txt`, printing nothing else. It uses only the Python standard library.
